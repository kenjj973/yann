# Projet Yann — Redesign Corteiz

Projet d'école : redesign du site Corteiz à partir de la maquette Figma.
Site statique en HTML / CSS / JavaScript, sans dépendance.

## Lancer le site

Ouvrir `index.html` dans un navigateur, ou lancer un petit serveur local :

```bash
python3 -m http.server 5173
```

puis aller sur http://localhost:5173.

## Fonctionnalités

- Recherche : la loupe s'étire en barre vers la gauche (raccourci `/`)
- Bouton de taille 16 / 24 / 34 px qui met tout le site à l'échelle
- Filtres par catégorie
- Fiche produit avec choix de taille et ajout au panier
- Panier avec quantités, total et sauvegarde dans le navigateur

## Contenu

- `index.html`, `styles.css`, `script.js` : le site
- `assets/` : logo, icônes et photos produits
- `docs/` : audit d'accessibilité (PDF)

Projet pédagogique, non affilié à Corteiz.
